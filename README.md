
# 📊 Return Analysis Dashboard

An interactive **Power BI dashboard** developed to analyze product returns, returned sales, profit loss, and return trends using the **Sample Superstore dataset**.
## 📷 Dashboard Preview

![Return Analysis Dashboard](Return%20analysis%20dashboard.jpeg)

## 🎯 Project Objective

The goal of this project is to analyze returned orders and identify patterns across customers, products, categories, regions, segments, states, and time periods.

## 📌 Key KPIs

* **Avg Return Value:** 609.81
* **Profit Loss:** 23.23K
* **Return Rate:** 5.91%
* **Returned Sales:** 180.50K
* **Returned Orders:** 296

## 📈 Dashboard Analysis

The dashboard provides analysis of:

* Returned sales by state
* Returned orders by segment
* Returned sales by category and sub-category
* Profit loss by month
* Returned sales by month
* Returned sales by region
* Top 5 customers by returned sales
* Top 5 returned products

## 🔎 Interactive Filters

Users can filter the dashboard by:

* Category
* Sub-Category
* Region
* Segment
* Year
* State

## 🛠️ Tools & Technologies

* **Power BI**
* **DAX**
* **Power Query**
* **Microsoft Excel**
* **Data Visualization**

## 📂 Dataset

The project uses the **Sample Superstore dataset**, including order and return information.

## 💡 Key Insights

The dashboard helps identify:

* Products and categories with higher return activity
* Regions and states contributing to returned sales
* Customer segments with more returned orders
* Monthly return and profit-loss trends
* Customers and products with high returned sales
